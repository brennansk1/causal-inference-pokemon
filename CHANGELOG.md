# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - Unreleased

### Added
- Complete textbook: 8 chapters + 4 appendices covering causal inference from undergraduate to PhD level
- 12 Jupyter notebooks with interactive widgets and exercises
- 11 simulated datasets with fully documented data generating processes
- `kanto_utils` helper package for data loading, plotting, and causal estimation
- Custom matplotlib Kanto theme
- Asset download scripts for Pokemon sprites from PokeAPI
- GitHub Actions CI/CD for tests, notebook validation, and PDF builds
- Trainer Card progress tracker
